Accounts are managed from the command line, deliberately — there is no self-service sign-up, and a password is never typed into a web form that could be logged. From the app folder: 

python auth.py list
python auth.py add-tenant <id> --name "<Client name>" --caterer "<Caterer>"
python auth.py add-user <name> --role client --tenant <id>
python auth.py add-user <name> --role admin
python auth.py set-password <name>

Each one’s data is their own.

Every purchase line, upload and saved analysis carries the client it belongs to, and every query is filtered by it. A client account cannot reach another client’s data even by guessing an internal id — the lookups check ownership, not just the id.
